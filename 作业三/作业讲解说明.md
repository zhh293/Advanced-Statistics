## 第3章 线性回归 概念题

### 第5题：最小二乘系数的线性组合性质

**核心知识点：线性平滑器（Linear Smoother）**

这道题要求证明简单线性回归中，拟合值可以表示为所有响应值的线性组合，且权重仅取决于预测变量的值。

**关键推导：**
- ŷᵢ = β̂₀ + β̂₁xᵢ = ȳ + β̂₁(xᵢ - x̄)
- 代入β̂₁ = Σⱼ(xⱼ - x̄)yⱼ / Σₖ(xₖ - x̄)²
- 最终得到 ŷᵢ = Σⱼ aᵢⱼ yⱼ，其中 aᵢⱼ = (1/n) + (xᵢ-x̄)(xⱼ-x̄)/Σₖ(xₖ-x̄)²

**直观理解：** 权重aᵢⱼ由两部分组成：(1)均等权重1/n（所有观测对ȳ的贡献），(2)根据xᵢ和xⱼ偏离均值的方向和大小给予的额外权重。

### 第14题：共线性

**对应代码文件：** `R代码/第14题_共线性模拟.R`

**核心知识点：多重共线性、VIF、高杠杆点的影响**

本题通过模拟数据揭示共线性的核心问题：

1. **现象**：x₁和x₂相关性0.835
2. **后果**：多元回归中单个系数不显著，但简单回归中各自显著
3. **原因**：共线性导致系数标准误膨胀（VIF≈3.3）
4. **敏感性**：单个异常观测可以完全改变共线性变量的显著性判定

**实际启示：**
- 共线性不影响预测精度，但严重影响系数解释
- 发现共线性后可以：删除变量、PCA降维、或使用正则化

## 第4章 分类 概念题

### 第1题：逻辑斯蒂函数等价证明

证明 p(X) = e^η/(1+e^η) 等价于 p/(1-p) = e^η（η=β₀+β₁X）。核心是代数变换：1-p = 1/(1+e^η)，做除法即得。

### 第2题：LDA判别函数推导

证明最大化后验概率等价于最大化δₖ(x)。关键：共同方差σ²使x²项消去，判别函数成为x的线性函数。

### 第4题：维度灾难

展示KNN在高维空间中的退化：p=100维时需要97.7%的范围才能包含10%的邻居。

### 第5题：LDA vs QDA

偏差-方差权衡在分类中的体现：线性边界→LDA好；非线性→QDA好；大样本有利于QDA。

### 第6题：逻辑斯蒂回归概率计算

直接代入公式：p = e^(β₀+β₁x₁+β₂x₂) / (1+e^(...))。反解学习时间需50小时。

### 第8题：训练错误率vs测试错误率

KNN(K=1)训练错误率=0%但测试=36%（过拟合）；逻辑斯蒂训练=20%，期望测试<30%。选逻辑斯蒂。

### 第9题：优势比转换

odds = p/(1-p)；p = odds/(1+odds)。
