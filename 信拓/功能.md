## 功能全景图

### 一、数据看板（Dashboard）— 首页总览

| 功能 | 说明 |
|------|------|
| 📊 **核心指标卡片** | 事故总数、涉及城市数、数据来源数、最新更新时间 |
| 📈 **事故原因分布** | 饼图/柱状图：酒驾、闯红灯、分心驾驶等占比 |
| 🕐 **24小时事故趋势** | 折线图：每小时事故数量曲线，标注早晚高峰 |
| 🚗 **车辆类型分布** | 玫瑰图：电动车、小轿车、货车等占比 |
| 🌙 **时段分布** | 早高峰/晚高峰/平峰/夜间 四段对比 |
| 🔥 **高发地点 TOP10** | 横向柱状图，一眼看出哪些区域事故最多 |
| ☁️ **关键词词云** | 从事故正文提取高频词 |

---

### 二、事故地图可视化

| 功能 | 说明 |
|------|------|
| 🗺️ **全国热力图** | 基于地理编码，事故点在地图上按数量显示气泡大小 |
| 🔍 **地区下钻** | 点击省份/城市查看该区域详细统计 |
| 📍 **地点搜索** | 输入地名筛选该区域的事故列表 |

---

### 三、事故数据管理

| 功能 | 说明 |
|------|------|
| 📋 **事故列表** | 分页表格，展示标题、地点、时间、来源 |
| 🔎 **多条件筛选** | 按事故原因、车辆类型、时段、来源网站、日期范围筛选 |
| 🔍 **关键词搜索** | 全文搜索标题和正文 |
| 📄 **事故详情** | 点击查看完整正文、发布时间、来源链接 |
| 📥 **数据导出** | 筛选结果导出 CSV / Excel |

---

### 四、关联规则挖掘（核心亮点）

| 功能 | 说明 |
|------|------|
| ⚙️ **参数可调** | 前端滑块调整 `最小支持度` 和 `最小置信度`，实时触发挖掘 |
| 📊 **规则列表** | 表格展示：前件 → 后件、支持度、置信度、提升度 |
| 🔽 **多维度排序** | 按提升度/置信度/支持度排序 |
| 🎯 **规则筛选** | 按包含的关键词过滤规则（如只看含"酒驾"的规则） |
| 💡 **规则解读** | 自动生成自然语言解读，如：*"平峰时段 + 电动车 → 闯红灯，置信度78%"* |
| 📈 **规则可视化** | 桑基图展示 时段→原因→车型 的流向关系 |

---

### 五、桑基图（特征流向）

| 功能 | 说明 |
|------|------|
| 🔀 **三层流向** | 时段(5类) → 事故原因(7类) → 车辆类型(6类) |
| 🖱️ **悬停高亮** | 鼠标悬停高亮关联路径，显示具体数量 |
| 📏 **流量筛选** | 过滤掉数量过少的边，图更清晰 |

---

### 六、爬虫管理

| 功能 | 说明 |
|------|------|
| 🕷️ **手动触发** | 一键启动爬虫，选择目标网站（温州/福建/铜仁/南京） |
| 📊 **实时进度** | 显示爬取进度：已爬/总数、当前页面 |
| 📝 **爬取日志** | 历史记录：时间、来源、成功数、失败数、错误信息 |
| ⏰ **定时任务** | 设置每天/每周自动爬取，保持数据更新 |
| 🔄 **增量更新** | 自动去重，只入库新数据 |

---

### 七、数据导入

| 功能 | 说明 |
|------|------|
| 📂 **CSV 导入** | 上传 CSV 文件批量导入（复用现有 `traffic_accidents_final.csv`） |
| 🔄 **自动特征提取** | 导入时自动提取事故原因、车辆类型、时段等特征 |
| 🗺️ **地理编码** | 自动将地名转为经纬度坐标 |
