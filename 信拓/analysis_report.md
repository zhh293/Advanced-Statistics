# 信号灯相关交通事故分析报告

## 1. 数据概览
本报告基于采集的1103条真实交通事故案例数据进行分析。数据主要来源于温州、福建、铜仁、南京等地交警官方“曝光台”，具有较高的可信度和代表性。

## 2. 核心统计发现

### 2.1 事故原因分布
| 排名 | 事故原因 | 占比 |
| :--- | :--- | :--- |
| 1 | **酒驾** | 18.2% |
| 2 | **分心驾驶** (玩手机等) | 15.5% |
| 3 | **闯红灯** | 12.1% |
| 4 | 超速 | 8.5% |
| 5 | 逆向行驶 | 6.3% |
> **结论:** 酒驾、分心驾驶和闯红灯是导致事故的三大主因，三者合计占比超过45%。

### 2.2 事故时段分布
| 排名 | 时段 | 占比 |
| :--- | :--- | :--- |
| 1 | **平峰** (9:00-17:00, 19:00-22:00) | 44.8% |
| 2 | **夜间** (22:00-次日5:00) | 28.6% |
| 3 | 早高峰 (7:00-9:00) | 15.2% |
| 4 | 晚高峰 (17:00-19:00) | 11.4% |
> **结论:** 平峰时段由于车流量相对较小，驾驶人警惕性下降，事故发生率反而最高。夜间事故占比较高，且通常后果更严重。

### 2.3 涉事车辆类型分布
| 排名 | 车辆类型 | 占比 |
| :--- | :--- | :--- |
| 1 | **小轿车** | 38.5% |
| 2 | **电动车** | 29.2% |
| 3 | **货车** | 15.3% |
| 4 | 摩托车/三轮车 | 12.4% |
| 5 | 行人 | 2.1% |
> **结论:** 小轿车和电动车是事故高发的两大主体，需重点关注。

### 2.4 高发地点 (基于文本初步提取)
*   松桃苗族自治县
*   玉屏侗族自治县
*   印江县
*   温州市
*   南京市
> 注：受限于原始数据中地点字段的粗略性，此分析仅为参考。建议成员C使用地图API进行精确地理编码后生成热力图。

## 3. 关联规则挖掘

采用Apriori算法（最小支持度0.05，最小置信度0.6），从事故特征中挖掘出以下强关联规则：

| 规则 (antecedents) | 结果 (consequents) | 支持度 | 置信度 | 提升度 |
| :--- | :--- | :--- | :--- | :--- |
| `{vehicle_type:电动车, time_period:平峰}` | `{accident_reason:闯红灯}` | 0.072 | 0.78 | 2.45 |
| `{vehicle_type:小轿车, accident_reason:分心驾驶}` | `{time_period:平峰}` | 0.055 | 0.69 | 1.88 |
| `{accident_reason:酒驾, time_period:夜间}` | `{vehicle_type:小轿车}` | 0.068 | 0.82 | 1.95 |

### 规则解读
1.  **规则1 (电动车 + 平峰 → 闯红灯)**：置信度78%，表明平峰时段电动车发生的交通事故极有可能由闯红灯引起。提示应在平峰时段加强对电动车闯红灯的执法。
2.  **规则2 (小轿车 + 分心驾驶 → 平峰)**：小轿车因分心驾驶导致的事故更多发生在平峰时段，可能是因为路况较好时驾驶人容易放松警惕。
3.  **规则3 (酒驾 + 夜间 → 小轿车)**：夜间酒驾事故中，小轿车占比高达82%，为夜间酒驾查缉提供了精准目标。

## 4. 预防建议

基于以上分析，提出以下两条可落地的预防建议：

### 建议一：针对电动车“平峰闯红灯”实施“潮汐式”执法与宣传
- **行动项**：在平峰时段（尤其是13:00-16:00）于主要路口增派警力，专项查处电动车闯红灯、逆行等行为。同时，利用社区宣传栏、微信公众号等渠道，在平峰时段精准推送电动车典型事故案例。

### 建议二：强化夜间小轿车酒驾查缉与分心驾驶技术防范
- **酒驾方面**：在重点餐饮、娱乐场所周边道路，于夜间21:00至次日凌晨2:00设立常态化检查点，利用大数据动态调整查缉位置。
- **分心驾驶方面**：推动升级电子警察，自动抓拍驾驶时使用手持电话的行为。在导航APP中增加平峰时段“请勿分心驾驶”的语音安全提示。
